Responsive Images in Bootstrap

A responsive image automatically becomes smaller when its parent container becomes smaller.

1. Use the .img-fluid class

Bootstrap's .img-fluid class applies these CSS rules: 

max-width: 100%;
height: auto;
  • max-width: 100% prevents the image from becoming wider than its container.
  • height: auto preserves the image's original proportions.

2. Live responsive example

Resize the browser window. The image will shrink with the container. 

<img src="mountain.jpg" class="img-fluid" alt="Mountain landscape">

3. The image follows its parent

This parent is only 360 pixels wide, so the same large image fits inside it.

4. Useful Bootstrap image classes

.rounded

Adds rounded corners.

.rounded-circle

Displays a square image as a circle.

.img-thumbnail

Adds a small border and padding.

5. Responsive image inside the Bootstrap grid

The columns stack on small screens and sit side by side on medium and larger screens.

Image and text

The image uses .img-fluid, while .col-md-6 controls the responsive column width.

Remember

Use class="img-fluid" on images that must fit their parent container. Always include meaningful alt text.
